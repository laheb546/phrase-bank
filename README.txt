English Phrase Bank — offline Android app (free)

This is an installable web app. All phrases, flashcards, and error counts
stay on your phone (local storage). No MongoDB, no VS Code, no monthly cost.

HOW TO PUT IT ON YOUR PHONE (free)

Option A — easiest (recommended)
1. Go to https://vercel.com and sign up free with GitHub, or use https://app.netlify.com/drop
2. Netlify Drop: drag this whole folder onto https://app.netlify.com/drop
3. Open the link Netlify gives you on your Android phone in Chrome
4. Chrome menu (three dots) → Add to Home screen / Install app
5. Open the icon. After the first open, it works offline (airplane mode).

Option B — already have the site online
Upload these files (index.html, manifest.json, sw.js, icon.svg) as a static site
and install the same way.

Notes
- Data lives only on that phone/browser. Clearing site data deletes it.
- Gallery photos: Flashcards → Gallery photos → save the PNG to Photos.
- Free forever for personal use.
